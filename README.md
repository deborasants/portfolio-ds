# Portfólio — Débora Santos

Portfólio mobile-first em português, com foco em Backend PHP / APIs.

## Stack

- React + Vite
- Framer Motion
- GitHub Pages (`/portfolio-ds/`)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Site: https://deborasants.github.io/portfolio-ds/
